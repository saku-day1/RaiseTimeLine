## インフラ構成（AWS）

ローカル開発環境とは別に、AWS上に本番相当の環境を構築する。
EC2上でNginxとSpring Bootを動かし、ALBでHTTPS通信を終端する。
画像ファイルはS3バケットに保存する。

### 構成図

```
インターネット
      ↓ HTTPS (443)
┌─────────────────────────────────────────────────────────┐
│  ALB（Application Load Balancer）                        │
│  リスナー: HTTPS:443 → ターゲットグループ（EC2:80）       │
│  SSL証明書: ACM（AWS Certificate Manager）               │
└──────────────────────────┬──────────────────────────────┘
                           ↓ HTTP:80
          ┌─────────────────────────────────────┐
          │  EC2 t3.small (Amazon Linux 2023)    │
          │                                     │
          │  Nginx（リバースプロキシ）             │
          │   ├── /        → React 静的ファイル  │
          │   └── /api/    → Spring Boot :8080  │
          │                                     │
          │  Spring Boot（ポート8080）            │
          │   ├── REST API 提供                  │
          │   ├── JWT 認証・認可                  │
          │   └── AWS SDK → S3 アップロード       │
          └───────────────┬─────────────────────┘
                          │
          ┌───────────────┴───────────────┐
          │                               │
          ↓ :5432（EC2 SG からのみ許可）   ↓ HTTPS（VPCエンドポイント経由）
   ┌─────────────┐               ┌──────────────────┐
   │ RDS          │               │ S3 Bucket         │
   │ db.t4g.micro │               │ 画像ファイル保存   │
   │ PostgreSQL17 │               │ （非公開バケット） │
   └─────────────┘               └──────────────────┘
```

### AWSリソース一覧

| リソース | 種別 | 用途 |
|---------|------|------|
| ALB | Application Load Balancer | HTTPS終端・EC2へのルーティング |
| EC2 | t3.small | Nginx + Spring Boot 稼働サーバー |
| RDS | db.t4g.micro (PostgreSQL 17) | データベース |
| S3 | バケット | 投稿画像・プロフィール画像の保存 |
| ACM | SSL証明書 | ALBのHTTPS通信用 |
| Security Group (EC2用) | - | ALBからのHTTP(80)・管理用SSH(22)を許可 |
| Security Group (RDS用) | - | EC2 SGからのポート5432のみ許可 |
| IAM Role (EC2用) | - | EC2からS3へのアクセス権限付与 |

### EC2 実行環境

| 項目 | 内容 |

## 対象外（スコープ外）

以下の機能・構成は今回の開発対象外とする。

| 項目 | 備考 |
|------|------|
| インプレッション・リポスト機能 | 意図的に除外（差別化ポイント） |
| DM・通知・ハッシュタグ機能 | 今回のスコープ外 |
| EC2 Auto Scaling | 学習フェーズでは単一インスタンス構成 |
| CloudFront（CDN） | 将来的な拡張候補 |
| Terraform によるIaC管理 | 将来的な拡張候補 |
| CI/CD パイプライン | 将来的な拡張候補 |
