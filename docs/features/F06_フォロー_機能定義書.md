# F06: フォロー・ユーザー検索 機能定義書

← [要件定義書に戻る](../../要件定義書.md)

---

## 概要

ログイン済みユーザーが他ユーザーをフォロー・アンフォローする機能。
ユーザー名の部分一致検索でフォロー対象を見つけることができる。

---

## 機能詳細

### ユーザー検索

- ユーザー名を入力して部分一致で検索する（大文字・小文字を区別しない）
- 検索結果には各ユーザーのアバター・ユーザー名・フォローボタンを表示する
- 自分自身は検索結果に含めない
- 検索結果のユーザーカードからそのままフォロー操作ができる

### フォロー操作

- 「フォロー」ボタンをクリックすると対象ユーザーをフォローする
- フォロー済みの場合は「フォロー中」ボタンが表示される
- 「フォロー中」ボタンをクリックするとアンフォローする
- 自分自身はフォローできない（APIレベルでも制限する）

### フォロー状態の表示

- ユーザープロフィール画面（S-07）にフォロー中・フォロワーの人数を表示する
- 相互フォローの場合は「相互フォロー」と表示する
- タイムラインの「ホーム」タブはフォロー中ユーザーの投稿のみを表示する（F02 参照）

---

## 画面との対応

| 操作 | 画面 |
|------|------|
| ユーザー検索 | S-06: ユーザー検索画面（`/search`） |
| フォロー・アンフォロー | S-06: ユーザー検索画面 または S-07: ユーザープロフィール画面 |
| フォロー数・フォロワー数表示 | S-07: ユーザープロフィール画面（`/users/:id`） |

---

## API エンドポイント（概要）

| メソッド | パス | 説明 | 認証 |
|---------|------|------|------|
| GET | `/api/users/search?q=:keyword` | ユーザー名検索 | 必要 |
| POST | `/api/users/:id/follow` | フォロー | 必要 |
| DELETE | `/api/users/:id/follow` | アンフォロー | 必要 |
| GET | `/api/users/:id/followers` | フォロワー一覧 | 不要 |
| GET | `/api/users/:id/following` | フォロー中一覧 | 不要 |
| GET | `/api/users/:id` | ユーザープロフィール取得 | 不要 |

---

## データ操作

| 操作 | テーブル | 内容 |
|------|---------|------|
| ユーザー検索 | users | SELECT WHERE username ILIKE '%:keyword%' AND id <> :currentUserId |
| フォロー | follows | INSERT（follower_id, following_id）ON CONFLICT DO NOTHING |
| アンフォロー | follows | DELETE WHERE follower_id = ? AND following_id = ? |
| フォロワー数 | follows | SELECT COUNT(*) WHERE following_id = ? |
| フォロー中数 | follows | SELECT COUNT(*) WHERE follower_id = ? |

---

## 制約

- `follows` テーブルの `(follower_id, following_id)` に UNIQUE 制約を設定する
- `follower_id <> following_id` のCHECK制約を設定し、自己フォローを禁止する

---

## スコープ外

- フォロー申請・承認フロー（非公開アカウント）
- ブロック機能
- フォロー通知
