# F01: 認証・アカウント管理 機能定義書

← [要件定義書に戻る](../../要件定義書.md)

---

## 概要

ユーザーがメールアドレスとパスワードでアカウントを作成・ログイン・ログアウトし、
プロフィール情報を管理する機能。

---

## 機能詳細

### アカウント登録

- ユーザー名・メールアドレス・パスワード・パスワード確認を入力してアカウントを作成する
- メールアドレスの重複チェックをバックエンドで実施する
- 登録成功後は自動ログインし、タイムライン画面へ遷移する

### ログイン

- メールアドレスとパスワードを入力してログインする
- 認証成功時にアクセストークン（15分有効）とリフレッシュトークン（7日有効）を発行し、フロントエンドに返却する
- フロントエンドはトークンを `localStorage` に保存する
- 認証失敗時は「メールアドレスまたはパスワードが正しくありません」と表示する

### トークン自動更新

- アクセストークンの有効期限が切れた場合（401レスポンス）、フロントエンドが自動的にリフレッシュエンドポイントを呼び出す
- リフレッシュ成功時は新しいアクセストークンとリフレッシュトークンを発行し、元のリクエストを再試行する（ローテーション方式）
- リフレッシュトークンも失効している場合はログイン画面へ遷移する

### ログアウト

- トークンを破棄し、ログイン画面へ遷移する

### プロフィール編集

- ユーザー名・自己紹介文・プロフィール画像を変更できる
- プロフィール画像はS3にアップロードしてURLをDBに保存する（F07 参照）

---

## 画面との対応

| 操作 | 画面 |
|------|------|
| アカウント登録 | S-02: 新規登録画面（`/register`） |
| ログイン | S-01: ログイン画面（`/login`） |
| ログアウト | ヘッダーのログアウトボタン |
| プロフィール編集 | S-08: マイプロフィール画面（`/profile`） |

---

## API エンドポイント（概要）

| メソッド | パス | 説明 | 認証 |
|---------|------|------|------|
| POST | `/api/auth/register` | アカウント登録 | 不要 |
| POST | `/api/auth/login` | ログイン・トークン発行 | 不要 |
| POST | `/api/auth/refresh` | アクセストークン再発行 | 不要 |
| PUT | `/api/users/me` | プロフィール更新 | 必要 |
| GET | `/api/users/me` | 自分のプロフィール取得 | 必要 |

---

## データ操作

| 操作 | テーブル | 内容 |
|------|---------|------|
| 登録 | users | INSERT（email, password_hash, username） |
| ログイン | users | SELECT WHERE email = ? → パスワード照合 |
| ログイン | refresh_tokens | INSERT（user_id, token, expires_at） |
| トークン更新 | refresh_tokens | SELECT WHERE token = ? → DELETE → INSERT |
| プロフィール更新 | users | UPDATE username, profile_image_url WHERE id = ? |

---

## トークン仕様

| 種別 | 有効期限 | 保存場所 | 用途 |
|------|---------|---------|------|
| アクセストークン | 15分 | localStorage | APIリクエストの認証 |
| リフレッシュトークン | 7日 | localStorage / refresh_tokens テーブル | アクセストークンの再発行 |

リフレッシュトークンはローテーション方式を採用する（再発行のたびに旧トークンを削除し新トークンを発行）。

---

## バリデーション

| フィールド | ルール |
|------------|--------|
| ユーザー名 | 必須・1〜50文字 |
| 自己紹介文 | 任意・0〜160文字 |
| メールアドレス | 必須・メール形式・重複なし |
| パスワード | 必須・8文字以上 |
| パスワード確認 | パスワードと一致 |

---

## スコープ外

- メールアドレスの変更機能
- パスワードのリセット機能
- ソーシャルログイン（OAuth）
