# F01: 認証・アカウント管理 機能定義書

← [要件定義書に戻る](../../要件定義書.md)

---

## 概要

ユーザーがメールアドレスとパスワードでアカウントを作成・ログイン・ログアウトし、
プロフィール情報を管理する機能。

---

## 機能詳細

### アカウント登録

- ユーザー名・メールアドレス・パスワード・パスワード確認を入力してアカウントを作成する
- メールアドレスの重複チェックをバックエンドで実施する
- 登録成功後は自動ログインし、タイムライン画面へ遷移する

### ログイン

- メールアドレスとパスワードを入力してログインする
- 認証成功時にJWT（アクセストークン）を発行し、フロントエンドに返却する
- フロントエンドはJWTを `localStorage` または `httpOnly Cookie` に保存する
- 認証失敗時は「メールアドレスまたはパスワードが正しくありません」と表示する

### ログアウト

- JWTを破棄し、ログイン画面へ遷移する

### プロフィール編集

- ユーザー名・自己紹介文・プロフィール画像を変更できる
- プロフィール画像はS3にアップロードしてURLをDBに保存する（F07 参照）

---

## 画面との対応

| 操作 | 画面 |
|------|------|
| アカウント登録 | S-02: 新規登録画面（`/register`） |
| ログイン | S-01: ログイン画面（`/login`） |
| ログアウト | ヘッダーのログアウトボタン |
| プロフィール編集 | S-08: マイプロフィール画面（`/profile`） |

---

## API エンドポイント（概要）

| メソッド | パス | 説明 | 認証 |
|---------|------|------|------|
| POST | `/api/auth/register` | アカウント登録 | 不要 |
| POST | `/api/auth/login` | ログイン・JWT発行 | 不要 |
| PUT | `/api/users/me` | プロフィール更新 | 必要 |
| GET | `/api/users/me` | 自分のプロフィール取得 | 必要 |

---

## データ操作

| 操作 | テーブル | 内容 |
|------|---------|------|
| 登録 | users | INSERT（email, password_hash, username） |
| ログイン | users | SELECT WHERE email = ? → パスワード照合 |
| プロフィール更新 | users | UPDATE username, profile_image_url WHERE id = ? |

---

## バリデーション

| フィールド | ルール |
|------------|--------|
| ユーザー名 | 必須・1〜50文字 |
| 自己紹介文 | 任意・0〜160文字 |
| メールアドレス | 必須・メール形式・重複なし |
| パスワード | 必須・8文字以上 |
| パスワード確認 | パスワードと一致 |

---

## スコープ外

- メールアドレスの変更機能
- パスワードのリセット機能
- ソーシャルログイン（OAuth）
