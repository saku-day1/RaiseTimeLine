# F04: コメント 機能定義書

← [要件定義書に戻る](../../要件定義書.md)

---

## 概要

ログイン済みユーザーが投稿に対してコメントを追加・削除する機能。
第三者（他ユーザー）によるコメントが可能で、コメント数はタイムライン上でも可視化される。

---

## 機能詳細

### コメント投稿

- ログイン済みユーザーは自分の投稿・他ユーザーの投稿どちらにもコメントできる
- コメント本文（必須・1〜200文字）を入力して送信する
- コメント成功後、入力欄をクリアして一覧の先頭に新しいコメントを追加表示する
- コメント数カウントが即座に更新される

### コメント一覧表示

- 投稿詳細ページ（S-05）にコメントを新着順で表示する
- コメント者のアバター・ユーザー名・投稿日時・コメント本文を表示する
- 未ログインユーザーもコメント一覧を閲覧できる

### コメント削除

- 自分が投稿したコメントのみ削除できる
- 削除後、コメント数カウントが即座に更新される

## 画面との対応

| 操作 | 画面 |
|------|------|
| コメント投稿 | S-05: 投稿詳細画面（`/posts/:id`） |
| コメント一覧表示 | S-05: 投稿詳細画面（`/posts/:id`） |
| コメント数表示 | S-03: タイムライン画面（`/`） |
| コメント削除 | S-05: 投稿詳細画面（`/posts/:id`） |

---

## API エンドポイント（概要）

| メソッド | パス | 説明 | 認証 |
|---------|------|------|------|
| POST | `/api/posts/:id/comments` | コメント投稿 | 必要 |
| GET | `/api/posts/:id/comments` | コメント一覧取得 | 不要 |
| DELETE | `/api/comments/:id` | コメント削除（自分のみ） | 必要 |

---

## データ操作

| 操作 | テーブル | 内容 |
|------|---------|------|
| コメント作成 | comments | INSERT（post_id, user_id, content） |
| コメント一覧取得 | comments, users | SELECT WHERE post_id = ? ORDER BY created_at DESC |
| コメント削除 | comments | DELETE WHERE id = ? AND user_id = ?（権限チェック） |

---

## バリデーション

| フィールド | ルール |
|------------|--------|
| コメント本文 | 必須・1〜200文字 |

## スコープ外

- コメントの編集（修正）
- コメントへのいいね
- コメントのネスト（返信コメント）
