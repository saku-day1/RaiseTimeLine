# F07: 画像投稿 機能定義書

← [要件定義書に戻る](../../要件定義書.md)

---

## 概要

投稿・プロフィール編集時に画像ファイルをAWS S3にアップロードし、
取得URLをデータベースに保存する機能。

---

## 機能詳細

### 画像選択とプレビュー

- ファイル選択ダイアログで画像ファイル（jpg / png / gif）を選択する
- 選択直後にブラウザ上でプレビューを表示する（`FileReader` API 使用）
- 「×」ボタンで選択を解除できる

### 画像アップロード（S3）

- フロントエンドからバックエンドへ `multipart/form-data` で画像ファイルを送信する
- バックエンドがAWS SDK（v2）を使用してS3バケットへアップロードする
- アップロード後のS3オブジェクトURLをDBの `image_url` カラムに保存する
- S3バケットはパブリックアクセスをブロックし、画像の表示はバックエンド経由 or プリサインドURLを使用する

### 利用箇所

| 機能 | 保存先カラム |
|------|------------|
| 投稿の画像添付 | `posts.image_url` |
| プロフィール画像変更 | `users.profile_image_url` |

---

## 画面との対応

| 操作 | 画面 |
|------|------|
| 投稿画像の選択・プレビュー | S-04: 投稿作成画面（`/posts/new`） |
| プロフィール画像の変更 | S-08: マイプロフィール画面（`/profile`） |

---

## API エンドポイント（概要）

| メソッド | パス | 説明 | 認証 |
|---------|------|------|------|
| POST | `/api/posts` | 投稿作成（画像含む multipart/form-data） | 必要 |
| PUT | `/api/users/me` | プロフィール更新（画像含む multipart/form-data） | 必要 |

---

## S3 構成

| 項目 | 内容 |
|------|------|
| バケット構成 | 投稿画像・プロフィール画像を1バケットで管理（プレフィックスで区別） |
| オブジェクトキー例 | `posts/{userId}/{uuid}.jpg` / `profiles/{userId}.jpg` |
| アクセス制御 | バケットのパブリックアクセスブロック有効 |
| 画像配信方法 | バックエンドがプリサインドURL（有効期限付き）を生成して返却する |
| EC2からのアクセス | IAM Role（EC2インスタンスプロファイル）で権限を付与 |

---

## バリデーション

| フィールド | ルール |
|------------|--------|
| ファイル形式 | jpg / png / gif のみ許可 |
| ファイルサイズ | 5MB以下 |

---

## スコープ外

- 複数枚画像の同時投稿
- 動画ファイルのアップロード
- 画像のトリミング・リサイズ（アップロード前加工）
- CloudFront による画像CDN配信
