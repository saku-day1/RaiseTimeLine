# F02: タイムライン 機能定義書

← [要件定義書に戻る](../../要件定義書.md)

---

## 概要

全ユーザーの投稿を新着順に一覧表示する機能。
ログイン済みユーザーは「ホーム（フォロー中）」と「すべて」のタブを切り替えられる。

---

## 機能詳細

### タブ切り替え

| タブ | 表示対象 | 利用可能ユーザー |
|------|---------|----------------|
| ホーム | フォローしているユーザーの投稿のみ | ログイン済みのみ |
| すべて | 全ユーザーの投稿 | 全ユーザー |

- 未ログインユーザーがアクセスした場合、「すべて」タブのみを表示する
- デフォルト表示: ログイン済みは「ホーム」、未ログインは「すべて」

### 投稿カードの表示内容

- 投稿者アバター・ユーザー名・投稿日時
- 投稿本文（最大140文字）
- 投稿画像（添付ありの場合のみ）
- いいね数・いいねボタン（自分のいいね状態をアイコン色で表示）
- コメント数・コメントアイコン（クリックで投稿詳細へ遷移）
- 削除ボタン（自分の投稿のみ表示）

### ページネーション

- 1回の取得件数: 20件
- 「もっと見る」ボタンまたは無限スクロールで追加読み込み

## API エンドポイント（概要）

| メソッド | パス | 説明 | 認証 |
|---------|------|------|------|
| GET | `/api/posts?tab=all&page=0&size=20` | すべての投稿一覧取得 | 不要 |
| GET | `/api/posts?tab=home&page=0&size=20` | フォロー中の投稿一覧取得 | 必要 |

## データ操作

### すべてタブ

```sql
SELECT p.*, u.username, u.profile_image_url,
       COUNT(DISTINCT l.id) AS like_count,
       COUNT(DISTINCT c.id) AS comment_count
FROM posts p
JOIN users u ON p.user_id = u.id
LEFT JOIN likes l ON p.id = l.post_id
LEFT JOIN comments c ON p.id = c.post_id
GROUP BY p.id, u.id
ORDER BY p.created_at DESC
LIMIT 20 OFFSET :offset;
```

### ホームタブ（フォロー中）

```sql
SELECT p.*, u.username, u.profile_image_url, ...
FROM posts p
JOIN users u ON p.user_id = u.id
JOIN follows f ON p.user_id = f.following_id AND f.follower_id = :currentUserId
LEFT JOIN likes l ON p.id = l.post_id
LEFT JOIN comments c ON p.id = c.post_id
GROUP BY p.id, u.id
ORDER BY p.created_at DESC
LIMIT 20 OFFSET :offset;
```
