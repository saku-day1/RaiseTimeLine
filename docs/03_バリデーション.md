# バリデーションルール

← [要件定義書に戻る](../要件定義書.md)

---

## 認証・アカウント登録

| フィールド | ルール | エラーメッセージ |
|------------|--------|----------------|
| ユーザー名 | 必須・1〜50文字（@識別子） | 「ユーザー名は1〜50文字で入力してください」 |
| 表示名 | 必須・1〜50文字 | 「表示名は1〜50文字で入力してください」 |
| メールアドレス | 必須・メール形式・重複なし | 「このメールアドレスは既に使用されています」 |
| パスワード | 必須・8文字以上 | 「パスワードは8文字以上で入力してください」 |
| パスワード確認 | 必須・パスワードと一致 | 「パスワードが一致しません」 |

---

## ログイン

| フィールド | ルール | エラーメッセージ |
|------------|--------|----------------|
| メールアドレス | 必須・メール形式 | 「メールアドレスを正しい形式で入力してください」 |
| パスワード | 必須 | 「パスワードを入力してください」 |
| 認証失敗時 | - | 「メールアドレスまたはパスワードが正しくありません」 |

---

## 投稿

| フィールド | ルール | エラーメッセージ |
|------------|--------|----------------|
| 本文 | 必須・1〜140文字 | 「本文は1〜140文字で入力してください」 |
| 画像 | 任意・jpg / png / gif・5MB以下 | 「5MB以下の画像（jpg / png / gif）を選択してください」 |

## プロフィール編集

| フィールド | ルール | エラーメッセージ |
|------------|--------|----------------|
| ユーザー名 | 必須・1〜50文字 | 「ユーザー名は1〜50文字で入力してください」 |
| 自己紹介文 | 任意・0〜160文字 | 「自己紹介文は160文字以内で入力してください」 |
| プロフィール画像 | 任意・jpg / png / gif・5MB以下 | 「5MB以下の画像（jpg / png / gif）を選択してください」 |

## バリデーション実施タイミング

| タイミング | 内容 |
|-----------|------|
| フロントエンド（送信前） | 必須チェック・文字数チェック・ファイルサイズチェック |
| バックエンド（APIリクエスト受信時） | 全項目の再バリデーション・重複チェック・権限チェック |
