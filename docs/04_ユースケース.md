# ユースケース・操作フロー

---

## UC01：ユーザー登録をする

```
1. 未ログインユーザーが新規登録画面（/register）にアクセスする
2. ユーザー名・メールアドレス・パスワード・パスワード確認を入力する
3. 「登録」ボタンをクリックする
4. バリデーションを実行する
   - エラーあり → エラーメッセージを表示し、フォームに留まる
   - エラーなし → アカウントを作成し、自動ログインしてタイムライン画面へ遷移する
```

---

## UC02：ログイン / ログアウトをする

```
【ログイン】
1. 未ログインユーザーがログイン画面（/login）にアクセスする
2. メールアドレスとパスワードを入力する
3. 「ログイン」ボタンをクリックする
4. 認証を実行する
   - 失敗 → エラーメッセージを表示する
   - 成功 → JWTを発行し、タイムライン画面へ遷移する

【ログアウト】
1. ログイン済みユーザーがヘッダーの「ログアウト」ボタンをクリックする
2. JWTを破棄してログイン画面へ遷移する
```

---

## UC03：投稿を作成する

```
1. ログイン済みユーザーがヘッダーの「新規投稿」ボタンをクリックする
2. 投稿作成画面（/posts/new）で本文を入力する
3. 必要に応じて画像ファイルを選択する（プレビュー表示）
4. 「投稿」ボタンをクリックする
5. バリデーションを実行する
   - エラーあり → エラーメッセージを表示し、フォームに留まる
   - エラーなし → 画像があればS3にアップロードし、投稿をDBに保存する
6. タイムライン画面へ遷移し、投稿が先頭に表示される
```

---

## UC04：投稿にいいねする / 取り消す

```
1. ログイン済みユーザーがタイムラインまたは投稿詳細ページのハートアイコンをクリックする

【いいねする】
2. いいねが未付与の場合 → いいねを付与し、カウントが1増える
   アイコンが塗りつぶしの赤ハートに変わる

【いいねを取り消す】
2. すでにいいね済みの場合 → いいねを取り消し、カウントが1減る
   アイコンが空のハートに戻る

※ 未ログインユーザーがクリックした場合 → ログイン画面へ誘導する
```

---

## UC05：投稿にコメントする

```
1. ユーザーが投稿詳細ページ（/posts/:id）にアクセスする
2. ログイン済みの場合、コメント入力欄が表示される
3. コメントを入力して「投稿」ボタンをクリックする
4. バリデーションを実行する
   - エラーあり → エラーメッセージを表示する
   - エラーなし → コメントをDBに保存し、コメント一覧の先頭に追加表示される
5. コメント数のカウントが1増える
```

---

## UC06：ユーザーを検索してフォローする

```
1. ログイン済みユーザーがヘッダーまたはナビゲーションから検索画面（/search）へ遷移する
2. 検索欄にユーザー名（の一部）を入力して検索ボタンをクリックする
3. 部分一致するユーザーが一覧表示される（自分自身は表示しない）
4. 検索結果のユーザーカードの「フォロー」ボタンをクリックする
   - フォロー済みの場合は「フォロー中」ボタンが表示される
5. follows テーブルにレコードを挿入し、ボタンが「フォロー中」に変わる

【アンフォロー】
4. 「フォロー中」ボタンをクリックする
5. follows テーブルのレコードを削除し、ボタンが「フォロー」に戻る
```

---

## UC07：タイムラインを「ホーム」と「すべて」で切り替える

```
1. ログイン済みユーザーがタイムライン画面（/）を開く
2. 画面上部に「ホーム」タブと「すべて」タブが表示される

【ホームタブ】
3. 「ホーム」タブをクリックすると、フォロー中ユーザーの投稿のみを新着順で表示する
   フォローしているユーザーがいない場合は「フォローしているユーザーがいません」と表示する

【すべてタブ】
3. 「すべて」タブをクリックすると、全ユーザーの投稿を新着順で表示する

※ 未ログインユーザーは「すべて」タブのみアクセス可能
```

---

## UC08：プロフィールを編集する

```
1. ログイン済みユーザーがプロフィール画面（/profile）にアクセスする
2. ユーザー名または画像を変更する
3. 「保存」ボタンをクリックする
4. バリデーションを実行する
   - エラーあり → エラーメッセージを表示する
   - エラーなし → 画像があればS3にアップロードし、DBを更新して完了メッセージを表示する
```
